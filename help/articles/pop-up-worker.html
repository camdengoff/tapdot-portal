A pop-up sheet shows another web page, like your prayer form, over your DoorStep page. Many websites, including most Squarespace sites, block being shown inside another page for security reasons. In a pop-up they appear blank.

The fix is a pop-up worker: a tiny free program on your own Cloudflare account that passes those pages through so they can show in a sheet.

What happens without one

New pages start with no worker. Until you add one, pop-up links simply open in a new tab instead, so they always work. You only need a worker if you want those pages to open in a sheet.

Set up your worker

This takes about ten minutes, once. You’ll need a free Cloudflare account.

  1. Copy the worker codeIn the editor, open the Publish tab → Pop-up proxy → Set up your own worker, then click 📋 Copy worker code.
  2. Sign in to CloudflareMake a free account at cloudflare.com if you don’t have one.
  3. Make a workerGo to Workers & Pages → Create → Start with Hello World. Name it, for example church-popups, and click Deploy.
  4. Paste the codeClick Edit code, delete everything there, paste the worker code and click Deploy.
  5. Copy its addressYour worker’s address ends in .workers.dev. Paste it into Worker address in the editor’s Publish tab.
  6. Tick the sites that need itA list of every site your pop-ups link to appears. Tick the ones that show up blank. Unticked sites load directly, as before.
  7. Update the workerTicking sites changes the worker code. Copy the code again, paste it over the old code in Cloudflare and deploy.
  8. PublishPublish your DoorStep page so it uses the worker.
Is it up to date?

Under the list of sites, the editor checks your worker. “✓ Your worker is up to date” means you’re done. If it names a site your worker doesn’t include yet, copy the code again and paste it into Cloudflare.

Good to know

  • The worker only passes through the sites you tick, so it can’t be used for anything else.
  • Cloudflare’s free plan is far more than a church page needs.
  • One worker can serve several pages: paste the same address into each one. The worker code only includes the sites ticked on the page you copied it from, so tick the same sites on each page. If one is missing, that page’s Publish tab will say so.
  • To skip the worker for a single link, tick Skip the pop-up proxy for this link in that button’s settings.
