Each page has a Settings screen. Open it with the ⚙ button on the page’s card in the portal.

Page name

The name your team sees in the portal. Change it and click Save. The page’s address and install code stay the same, so your website and tags keep working.

Advanced editing

Off by default, to keep the editor simple and let the Theme set the look. Turn it on and every block in the editor gets a Style overrides group with:

  • Its own card, pressed card, text, secondary text and accent colors. Leave a color blank to use the theme’s.
  • Its own corner radius, space above and side margin. Slide all the way left to use the theme’s. A side margin of 0 makes a block run edge to edge.
  • An Anchor name, like events. Buttons can then Scroll to a block to jump to it.
  • An Extra CSS class, for anyone comfortable writing custom code in a Custom HTML block.

Styles you set stay on the page if you turn Advanced editing off later. They’re just hidden from the editor.

Install code

The same two lines as 📋 Install code on the page card, with a ↗ Live page link once the page is published. See Put your page on your website.
