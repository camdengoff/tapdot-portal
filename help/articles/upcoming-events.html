The Upcoming events block shows the next events from a Squarespace Events page. Add an event on your website and it appears on your tap page; once it’s over, it drops off.

Add your events

  1. Find your events pageOn your website, open the events page and copy its address, like https://yourchurch.org/events.
  2. Add the blockClick + Add block → 📅 Upcoming events.
  3. Paste the address with ?format=jsonIn the address box, paste it with ?format=json added to the end: https://yourchurch.org/events?format=json.
  4. Choose how manySet How many events (1 to 10) and your Time zone, so times show correctly.
  5. Check the previewYour next events should appear. Then publish.

With Tap opens event details sheet ticked, tapping an event shows its details in a sheet, without leaving the page.

Not on Squarespace?

This block reads Squarespace events pages. If your events live somewhere else and that site has an RSS feed, try the RSS feed block instead.

If events don’t show

  • Check that ?format=json is on the end of the address, with no spaces.
  • Open the events page in your browser and check it has upcoming events, not only past ones.
  • Under More options, keep Retry through public proxies if blocked ticked when the DoorStep page isn’t on the same Squarespace site as the events.
  • You can change the Loading message and Error message there too.
