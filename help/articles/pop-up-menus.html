A pop-up menu is a list of choices that slides up from the bottom of the screen when someone taps a button. It keeps your page short: one “Next steps” button can hold six choices.

Make a pop-up menu

  1. Open the Pop-ups tabClick + Add pop-up menu.
  2. Give it a title and iconFor example “Next steps” with ✚, and an optional subtitle like “Pick where you’d like to start”.
  3. Add menu itemsEach item has an icon, an icon background color, a title, a short description and a When tapped action, like a phone number, an email or a page in a pop-up sheet.

Open it from a button

  1. Pick a buttonAny button, banner, card, slide or hero.
  2. Set When tappedChoose Open one of my pop-up menus or lists.
  3. Pick the menuChoose your menu from the list, then try it in the preview.
Not just menus

The same choice also opens a connect card set to show in a pop-up and an RSS feed list set to show in a pop-up.

Ideas

  • Contact us: call the office, send a text, email, get directions. The Sunday welcome template has one ready to edit.
  • Next steps: baptism, membership class, serve, join a group.
  • Kids: check-in, this month’s lesson, the kids’ pastor’s email.
Tip

A menu item can’t open another pop-up menu. Keep each menu to one level, and link straight to the thing people want.
