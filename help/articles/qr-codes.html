DoorStep has its own QR code maker. The codes it makes are static: the address is written into the code itself, with nothing in between. They keep working forever, with no subscription, and they don’t depend on DoorStep staying online.

Make one

  1. Open QR codesOn your church’s screen, click ⊞ QR codes in the bar at the bottom. Or click ••• → QR code on a page’s card to start with that page.
  2. Choose what it opensYour page uses the page’s live link. Web address takes any link, like the page on your own website where you pasted the install code. You can also make codes that start an email, call a phone number, or show some text.
  3. Pick colors and shapeChoose a color or type a hex code (like #CC4410), and pick square, rounded or dot-shaped dots and corners.
  4. Add a logo (optional)Click + Add a logo. It goes in the middle, and the code uses extra error correction so it still scans.
  5. Check it scansUnder the picture, ✓ Scans means DoorStep read the code back correctly. If it says it didn’t scan, make the logo smaller or use darker dots.
  6. DownloadSVG stays sharp at any size and is best for printers and designers. PNG works everywhere; set the size in pixels (1,200 or more for print). Copy puts the picture on your clipboard to paste into a bulletin or slide.

DoorStep remembers your colors, shape and logo in this browser, so the next code matches.

Tips for codes that always scan

  • Keep the dots dark and the background light. Light dots on a dark background don’t scan on many phones.
  • Leave the border at 2 dots or more, and don’t print anything right up against the code.
  • Print it at least 2 cm (¾ inch) across for something held in the hand; bigger for a poster across a room.
  • Shorter links make simpler codes that scan from farther away.
  • Test the printed code with a couple of different phones before you print a lot.
Pick one address and stick with it

A static code can’t be changed after it’s printed. That’s fine for DoorStep pages, because the address stays the same when you publish new content. Just decide between your website page and the live link before you print. See Tap tags and QR codes.
