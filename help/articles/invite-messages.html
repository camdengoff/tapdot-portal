Most people come to church because someone invited them. The hard part for many is knowing what to say. The Invite messages block gives your people a few ready-written invites, so inviting a friend takes one tap.

What visitors see

A card with your title and a short line, then each invite shown as a message bubble. Under each one:

  • Copy copies the invite so they can paste it anywhere.
  • Send opens their phone’s share sheet (Messages, WhatsApp, Instagram and so on) with the invite already written. On a phone or browser without a share sheet, it opens a new text message instead.

Set it up

  1. Add the blockClick + Add block → 💌 Invite messages. It comes with one example invite.
  2. Set the title and lineFor example “Invite a friend” and “Pick a message, then copy it or send it.”
  3. Write your invitesUnder Invites, open each one. Give it an optional name (like “Sunday invite”), write The invite people send, and set the Message after copying, like “Invite copied. Paste it in a text!”
  4. Choose the buttonsRename Copy if you like, and keep Show a Send button ticked.

Write a good invite

  • Write it the way a friend would text it, in the first person: “I’ve been going to…”.
  • Include the day, the time and one link, like your plan-a-visit page.
  • Offer a couple of tones: a Sunday invite, a casual “coffee first?” and one for an upcoming event like Easter.
  • Keep it short. People can add their own words before they send it.
Example

Hey! I’ve been going to Grace Church and I think you’d love it. Want to come with me this Sunday? Services are at 9 and 10:45. gracechurch.org/visit

See which invites get used

Copy and Send taps are counted in tap stats, named with the invite they belong to, so you can see which message people pick most.
