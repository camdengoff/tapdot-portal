Each DoorStep page has an install code: two short lines that load the page onto your website. You paste it once. From then on, every time you publish, the page on your website updates by itself.

It looks like this (yours has your church’s and page’s names in it):

<div class="tapdot-page" data-page="your-church/welcome"></div>
<script src="https://doorstep.camdengoff.com/embed.js"></script>

Copy the install code

Use any of these. They all copy the same thing:

  • 📋 Install code on the page’s card in the portal.
  • The page’s ⚙ Settings screen.
  • In the editor, the Publish tab → 📋 Copy install code.
One code per page

Each page has its own install code. If you have a welcome page and a connect card page, paste each one on its own website page.

On Squarespace

  1. Make a page for itIn Squarespace, go to Pages, click + and add a Blank page. Give it a short address, like /welcome or /tap, because that’s what your tags and QR codes will open. To keep it out of your site’s menu, put it under Not linked.
  2. Add a Code blockEdit the page, click Add block (or +) and choose Code.
  3. Paste the install codeDelete the example text in the Code block, paste your two lines, and make sure the mode is HTML. Leave “Display source” off.
  4. SaveClick Save (or Done), then publish the Squarespace page if it isn’t public yet.
  5. Publish in DoorStepIf you haven’t published the DoorStep page yet, do that now. See Publish your changes.
  6. Check it on your phoneOpen the website page on your phone. You should see your DoorStep page filling the screen.
Squarespace plans

Squarespace only runs code like this on some plans. If the page stays blank and you’re on a Personal plan, check your plan in Squarespace’s billing settings. Until then you can use the page’s live link, which works without a website.

On other websites

Any website builder that lets you add your own HTML works. Look for a block called Code, Custom HTML, Embed or HTML, paste the two lines and save. In WordPress, use the Custom HTML block.

Page options

In the editor’s Publish tab, under Page options:

  • Squarespace code block fixes (on by default) gives the whole website page your page’s background color, removes Squarespace’s padding around the block and hides the site search bar. Leave it on for Squarespace.
  • Layout: Full-screen app (the default) fills the whole screen, covering the website’s header and footer, so it feels like an app. Inline sits in the page between your website’s other content.

Publish after changing these, like any other edit.

You only do this once

Don’t paste the code again when you change the page. The install code always loads what you last published, so your website page, tags and QR codes stay the same forever.
