The Countdown block shows the days, hours, minutes and seconds until a date and time. It builds a little excitement, and it can tidy itself away when the moment arrives.

Set it up

  1. Add the blockClick + Add block → ⏳ Countdown.
  2. Write the labelLike “Christmas Eve services start in”. Add a Subheading and the label becomes a bold heading above it.
  3. Set the date and timeFill in Counts down to and choose your Time zone, so it hits zero at the right moment wherever someone is.
  4. Pick a number styleBoxes puts each number in its own tile. Slot machine rolls the numbers up, with no boxes.
  5. Decide what happens at zeroWrite the Text when finished, like “Happening now!”, or tick Hide the block when finished.

Add buttons

  • Button text and Button action add a button under the countdown, like “Learn more” or “Register”. It only shows once its action does something.
  • Second link (optional) adds another, like “Serve at the Block Party”, either as a bar along the bottom of the card or as an outline button next to the first one. Add an emoji before its text if you like.

Add a photo

Under Photo (optional), add a photo and choose Above the countdown or Behind the countdown. Behind the countdown, use Darken photo so the numbers stay easy to read.

Tip

Pair a countdown with a special time: show it only in the weeks before the event, and the page goes back to normal afterward by itself.
